# Oreo the Dog: Game of the Year

A celebratory WebGL adventure built with Vite, TypeScript, and Three.js featuring Oreo the dog as the undisputed Game of the Year champion. Guide Oreo around the awards plaza, scoop up celebratory biscuits, and bask in dynamic lighting that reflects Oreo's ever-optimistic mood.

## Getting started

```bash
npm install
npm run dev
```

Visit `http://localhost:5173` to play. Use **WASD** or the arrow keys to move, and press **space** to let Oreo bark triumphantly.

## Scripts

- `npm run dev` – Start the Vite dev server.
- `npm run build` – Generate a production build.
- `npm run preview` – Preview the production build locally.
- `npm test` – Run Vitest unit tests to keep Oreo in championship form.

## Features

- Hand-crafted 3D Oreo model complete with wagging tail, expressive ears, and animated trot.
- Award plaza environment with dynamic day-night lighting, volumetric fog, and celebratory particles.
- Collectible biscuit gameplay loop with real-time HUD updates and mood tracking.
- Orbiting cinematic camera that keeps the focus on Oreo's celebratory strut.
